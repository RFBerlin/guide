4Resources

GPUs are shared. Request only what you use.

5SSH key

You log in with an SSH key; there are no passwords. Paste your public key (the .pub file).

How do I get an SSH key?

Open a terminal (Windows: PowerShell; macOS/Linux: Terminal) and run:

ssh-keygen -t ed25519 -C "you@example.com"

Press Enter to accept the defaults. Then print the public key and paste it above:

cat ~/.ssh/id_ed25519.pub

Never share the file without .pub; that is your private key.

Your project

Fill in the form on the left to create your project.
Request container
  1. Download the project and unzip it.
  2. Create a private repository on GitHub and push the folder: git init && git add . && git commit -m "init" && git branch -M main && git remote add origin https://github.com/<you>/<repo>.git && git push -u origin main
  3. Add two repository secrets (Settings → Secrets and variables → Actions): DOCKER_USERNAME = your Docker Hub username, DOCKER_PASSWORD = a Docker Hub access token with Read & Write.
  4. Check the Actions tab: the build must turn green (re-run it if it ran before you added the secrets).
  5. Request your container with the button above. You'll get your port number when it's running, then connect with ssh -p <port> ubuntu@<server>.
Only /home/ubuntu/work is kept when your container updates or restarts. Keep code and data there.
